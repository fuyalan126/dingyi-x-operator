# Visual Strategy

Use this file when deciding whether and how a post should include an image.

## Default choices

- Default aspect ratio: `16:9`
- Use `1:1` for quote cards or dense explainers
- Keep text in image sparse
- Optimize for small-feed readability first

## Default mapping

- opinion -> reaction-visual or no image
- resource-share -> cover-card
- launch -> cover-card or reaction-visual
- thread -> thread-header
- explainer -> explainer-graphic or diagram
- case-study -> quote-card or explainer-graphic

## Skip image when

- the post is already strong text-only
- the image would only decorate, not clarify
- the likely output would feel generic

## Prefer image when

- the post links out and needs stronger click appeal
- the idea is easier to grasp visually
- the account is building a repeatable visual identity

## Visual brief checklist

- post type
- audience
- visual type
- one-sentence rationale
- art direction
- aspect ratio
- text density
- generation-ready prompt
- optional generation tool recommendation
